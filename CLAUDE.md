# Foco — app de produtividade para TDAH

Leia antes de qualquer trabalho: `docs/PRODUTO.md` (o quê e por quê) e `docs/ARQUITETURA.md` (stack, pastas, donos, modelo de dados).

- Idioma da UI e dos textos: português do Brasil.
- Edite apenas a pasta da qual você é dono (ver ARQUITETURA.md). Peça ao dono via `maestri ask` quando precisar de algo de outra área.
- Antes de entregar: `npm run typecheck && npm test && npm run build`.
- Não faça commits; o orquestrador integra e commita.
